# Osa Peninsula Forest Change Map

This is an **interactive web map** showing land cover changes in the **Osa Peninsula, Costa Rica**, between **2000 and 2024**.

The map visualizes **forest, regeneration, non-forest, and water areas** and allows users to explore changes over time.

## How to Use

1. Open `index.html` in a web browser.
2. Use the layer toggle to switch between the years 2000 and 2024.
3. Click on polygons to view the land cover class and area.

## Technologies

- **QGIS** – for land cover classification
- **Leaflet.js** – for interactive mapping
- **GeoJSON** – polygon data format
